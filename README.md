# نبض | NABD

واجهة عربية وإنجليزية لمحطة نبض الصحية المشتركة.

Static HTML, CSS, and JavaScript. Open index.html or publish the repository root through GitHub Pages (main / root). No build step required.

Fingerprint identification, medical measurements, and station distances are demonstration data. Walk records are stored locally in the browser; no backend or cross-device synchronization is provided.

Weather: Open-Meteo (location permission required). Font: Tajawal via Google Fonts.
